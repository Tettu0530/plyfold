# 多言語化（i18n）の決まり

画面の文言は日本語、英語、中国語（簡体）。韓国語は、辞書のファイルを足すだけで増やせるようにしてある。

## 仕組み

- 実装: `apps/desktop/src/i18n/index.ts`
- 辞書: `apps/desktop/src/i18n/<言語>/<名前空間>.ts`。**日本語（`ja/`）が元**で、ほかの言語は `Record<keyof typeof source, string>` で同じキーを型で強いる（足りない・余るキーは型の誤りになる）
- 名前空間ごとに、どのファイルの文かを冒頭のコメントに書いてある。新しい名前空間を足すときだけ `ja/index.ts` と `en/index.ts` を触る
- 部品の中: `const t = useT();` → `t("sidebar.newSession")`。言語が変わると描き直す
- 部品の外（store、lib）: `import { t } from "@/i18n"` の `t()`。呼んだときの言語で引く
- 言語の設定: 設定の「言語」（`settings.json` の `language`。`auto` なら macOS の言語、分からなければ英語）

## 書き方

- キーは lowerCamelCase の英語で、意味が分かる名前（`newSession`、`commitPlaceholder`）。文の中身を写した長いキーにしない
- 差し込みは `{name}`。数で形が変わる文は ICU の複数形: `"{count, plural, one {# file} other {# files}}"`（`#` が数）。日本語は `"{count} 件"` でよい（複数形の区別がない）
- 文を部品で組み立てない。語順は言語で違うので、1 つの文は 1 つのキーにして差し込みで渡す（`"「{title}」を消します"` / `"Delete “{title}”"`）
- 置き換えないもの: コマンド、パス、識別子、ACP や git の用語（`worktree`、`diff`、`model`、`effort`、`mode`、`--no-ff`）、キーの組み合わせ（`Keys` の部品）、プロバイダーやエージェントの名前（Claude Code、Codex、OpenCode、Gemini CLI）
- コメントは日本語のまま（訳さない）
- `aria-label`、`title`、`placeholder` も訳す
- 開発用の画面（動きの見本）も訳す

## 英語の文体

- 文の頭だけ大文字（sentence case）: "New session"、"Open in editor"。見出しやボタンも同じ（Title Case にしない）
- ボタンは動詞で始める短い命令形: "Stop"、"Merge"、"Create PR"、"Discard"。ピリオドを付けない
- 説明文は短い平叙文。ピリオドで終える。"You can …" "Please …" で始めない。感嘆符を使わない
- 状態は短い形容詞か分詞: "Working"、"Waiting for permission"、"Stalled"、"Idle"、"Stopped"
- 時間の短い形: `12s`、`3m`、`2h`、`yesterday`、`5d`
- 数の単位は複数形を正しく（"1 file" / "2 files"）。日本語の「件」を "items" と機械的に訳さず、何の数かを書く
- 日本語の「〜します」をそのまま "Will …" にしない。画面の説明は現在形で

## 中国語（簡体）の文体

- 対象は中国大陸の簡体字（zh-CN）。繁体字は使わない。ソフトウェアの UI でよく使われる、短く平易な語を選ぶ
- ボタンは 2〜4 字の動詞を中心に: 「停止」「合并」「放弃」「复制」「发送」。句点を付けない
- 説明文は「。」で終える。「请」は、操作を頼む文（例: 请先提交）だけに使い、乱用しない。感嘆号を使わない
- 句読点は全角（，。：（）「」）。ただし英数字やコード、パスに付く括弧や記号は半角のまま
- 中国語と英数字のあいだには半角の空白を入れる（「打开 worktree」「3 个文件」）
- 数は量詞を付ける（「3 个文件」「2 个会话」「5 轮」）。複数形の区別はないので ICU の plural は `other` だけでよい
- 時間の短い形: `12秒`、`3分钟`、`2小时`、`昨天`、`5天`

## フォントと字形

- 漢字は日本語と中国語で字形が違う（「直」「骨」「誤」など）。画面の言語は `<html lang>`（`ja` / `en` / `zh-CN`）で示し、`index.css` の `--font-cjk` を `:root:lang(..)` で切り替える（日本語はヒラギノ角ゴ、中国語は PingFang SC）
- 会話の本文（エージェントの出力、自分の発言、考えた内容）は、画面の言語と別に、本文の言語で描く: `contentLang(text)`（かなを含めば `ja`、ハングルなら `ko`）を `lang` に入れ、`[lang="ja"]` などでフォントを替える

## 言語を足すとき（中国語、韓国語）

1. `src/i18n/<lang>/` に、`en/` と同じ形のファイルを名前空間ごとに作る（型が足りないキーを教える）
2. `src/i18n/index.ts` の `Lang`、`LANGS`、`HTML_LANG`、`DICTS`、`detectLang`、`resolveLang` と、`lib/types.ts` の `AppSettings.language` に足す（設定の選択肢は `LANGS` から作る）
3. 漢字やハングルのフォント: `index.css` の `--font-cjk` を `:root:lang(..)` で足す（中国語は PingFang SC。日本語のフォントで描くと字形が日本語になる）
4. エンジンの文: `crates/plyfold-i18n` の `Lang` と `set_lang`、`tr!` の引数に足し、すべての `tr!` に文を足す（省けない）
